פרק ראשון - שאלות קצרות
1.
ענו על שניים מארבעת הסעיפים א-ד שלפניכם. אם תענו על יותר משני סעיפים, ייבדקו רק שתי התשובות הראשונות שבמחברתכם.
א.
(1)הוכיחו באינדוקצייה מתמטית, או בכל דרך אחרת, את השוויון שלהלן לכל n טבעי:
12 + 24 + 38 + ... + n2n = 2 - n + 22n
(2)קבעו אם יש מספר טבעי n שבעבורו הסכום שבאגף שמאל שווה בדיוק ל־2, ונמקו את קביעתכם. מצאו את המספר הטבעי n הקטן ביותר שבעבורו סכום זה גדול מ־1.99.
פתרון סעיף א הדרך: באגף שמאל סכום שמספר איבריו גדל, ובאגף ימין ביטוי סגור. בצעד האינדוקצייה מוסיפים לשני האגפים את האיבר הבא בלבד, n + 12n+1 , ולכן כל העבודה שם היא איחוד שני שברים למכנה המשותף 2n+1. שימו לב לצורת אגף ימין: הוא 2 פחות ביטוי חיובי, ומכאן ששני חלקי סעיף (2) נובעים ממנו ישירות, בלי לחשב את הסכום עצמו.
(1) בסיס האינדוקצייה (n = 1): אגף שמאל 12 , ואגף ימין 2 - 32 = 12 , ואכן שווים.
צעד האינדוקצייה: נניח כי בעבור n מסוים מתקיים 12 + 24 + 38 + ... + n2n = 2 - n + 22n , ונוסיף לשני האגפים את האיבר הבא n + 12n+1:
12 + 24 + 38 + ... + n2n + n + 12n+1 = 2 - n + 22n + n + 12n+1
= 2 - 2(n + 2) - (n + 1)2n+1 = 2 - n + 32n+1 ,
וזהו בדיוק אגף ימין בעבור n + 1 , שהרי (n + 1) + 2 = n + 3. בדקנו את הבסיס והוכחנו את הצעד, ועל פי עקרון האינדוקצייה השוויון נכון לכל n טבעי. ∎
(בדיקה עצמאית: בעבור n = 3 אגף שמאל הוא 12 + 24 + 38 = 118 , ואגף ימין 2 - 58 = 118.)
(2) אין מספר כזה. בעבור כל n טבעי הביטוי n + 22n חיובי ממש, ולכן
Sn = 2 - n + 22n < 2
בעבור כל n טבעי. הסכום מתקרב אל 2 ככל ש־n גדל, אך אינו מגיע אליו אף פעם.
כדי למצוא את n הקטן ביותר שבעבורו הסכום גדול מ־1.99 נדרוש
2 - n + 22n > 1.99  ⇐⇒  n + 22n < 0.01  ⇐⇒  100(n + 2) < 2n.
בעבור n = 10: 100·12 = 1200 ואילו 210 = 1024 , ואי־השוויון אינו מתקיים.
בעבור n = 11: 100·13 = 1300 ואילו 211 = 2048 , ואי־השוויון מתקיים.
אגף שמאל גדל בקצב קבוע ואילו אגף ימין מוכפל פי 2 בכל צעד, ולכן מרגע שאי־השוויון מתקיים הוא ממשיך להתקיים; המספר המבוקש הוא אפוא n = 11.
(בדיקה: S10 = 2 - 121024 ≈ 1.9883 , הקטן מ־1.99 , ואילו S11 = 2 - 132048 ≈ 1.9937 , הגדול ממנו.)
ב. מטילים קובייה הוגנת שלוש פעמים, בזו אחר זו, ורושמים את שלוש התוצאות.
(1)מהי ההסתברות שהתוצאה הגדולה ביותר מבין שלוש התוצאות שהתקבלו היא 4?
(2)ידוע כי התוצאה הגדולה ביותר מבין שלוש התוצאות היא 4. מהי ההסתברות שהתוצאה 4 התקבלה בדיוק פעם אחת?
פתרון סעיף ב הדרך: את המאורע "הגדול ביותר הוא 4" קשה לספור ישירות, כי הוא מורכב משלושה מקרים לפי מספר הפעמים שהופיע 4. לעומת זאת את המאורע "הגדול ביותר קטן או שווה ל־4" קל מאוד לחשב, כי הוא פשוט אומר שכל שלוש התוצאות מתוך {1,2,3,4}. לכן מחשבים שני מאורעות "עד" ומחסירים אותם. בסעיף (2) המכנה הוא בדיוק מה שחושב בסעיף (1).
(1) ההטלות בלתי תלויות, ולכן
P(כל התוצאות ≤ 4) = (46)3 = 64216 , P(כל התוצאות ≤ 3) = (36)3 = 27216.
המאורע השני מוכל בראשון, ולכן
P(הגדולה ביותר היא 4) = 64216 - 27216 = 37216 ≈ 0.171.
(2) נחשב תחילה את ההסתברות שהתקבל 4 בדיוק פעם אחת ושתי התוצאות האחרות קטנות מ־4: יש 3 אפשרויות לבחור באיזו הטלה התקבל 4, ההסתברות לכך היא 16, ובכל אחת משתי ההטלות האחרות ההסתברות לתוצאה מתוך {1,2,3} היא 36:
3 · 16 · (36)2 = 324 = 27216.
מאורע זה כולו מוכל במאורע שבסעיף (1), ולכן לפי הגדרת ההסתברות המותנית:
P(בדיוק 4 אחד | הגדולה ביותר היא 4) = 2721637216 = 2737 ≈ 0.730.
(בדיקה בספירה: מבין 216 השלשות האפשריות, 43 - 33 = 37 שלשות שהגדולה בהן היא 4; מהן 3·32 = 27 שלשות ובהן 4 אחד בלבד, 3·3 = 9 שלשות ובהן שני מספרי 4, ושלשה אחת ובה שלושה, וסך הכול 27 + 9 + 1 = 37.)
ג. בסרטוט שלפניכם מעגל שמרכזו O ורדיוסו 12. הנקודות A ו־B נמצאות על המעגל, והזווית המרכזית ∡AOB היא 120°. הנקודה C נמצאת על הקשת הגדולה AB, כמתואר בסרטוט.
(1)חשבו את הזווית ∡ACB ואת אורך המיתר AB.
(2)חשבו את אורך הקשת הקטנה AB ואת שטח הגזרה הקטנה AOB.
(3)חשבו את שטח החלק הכלוא בין המיתר AB ובין הקשת הקטנה AB.
פתרון סעיף ג הדרך: הזווית המרכזית היא הנתון שממנו נובע כאן הכול. היא נותנת את הזווית ההיקפית (מחצית ממנה), היא נותנת את המיתר (דרך המשולש שווה־השוקיים AOB), והיא נותנת את הקשת ואת הגזרה כחלק יחסי מן המעגל כולו: 120° הם שליש מ־360°. סעיף (3) הוא הפרש של שתי צורות שכבר חושבו, ולא חישוב חדש.
(1) הזווית ∡ACB היא זווית היקפית הנשענת על הקשת הקטנה AB, ואילו ∡AOB היא הזווית המרכזית הנשענת על אותה קשת, ולכן
∡ACB = 12·∡AOB = 12·120° = 60°.
המשולש AOB שווה־שוקיים (OA = OB = 12), ולכן האנך מן המרכז אל המיתר חוצה גם את המיתר וגם את זווית הראש. במשולש ישר־הזווית שנוצר, חצי הזווית הוא 60°, ולכן
AB = 2·12·sin 60° = 24·32 = 123 ≈ 20.78.
(בדיקה במשפט הקוסינוסים במשולש AOB: AB2 = 122 + 122 - 2·12·12·cos 120° = 288 + 144 = 432, ואכן 432 = 123.)
(2) הזווית המרכזית היא 120°, כלומר 120360 = 13 מן המעגל:
אורך הקשת: 13·2π·12 = 8π ≈ 25.13.
שטח הגזרה: 13·π·122 = 48π ≈ 150.80.
(3) החלק המבוקש הוא הגזרה פחות המשולש AOB:
שטח(AOB) = 12·12·12·sin 120° = 72·32 = 363 ≈ 62.35,
S = 48π - 363 ≈ 150.796 - 62.354 = 88.44.
(בדיקת סבירות: השטח שהתקבל קטן משטח הגזרה וגדול ממחציתה, וזה מה שהעין רואה בסרטוט.)
ד. נתונה הפונקצייה f(x) = x2 + 2 ונתונה הנקודה P(0 , -2), שאינה על גרף הפונקצייה.
(1)מצאו את משוואות שני המשיקים לגרף הפונקצייה f(x) העוברים דרך הנקודה P, ואת שיעורי נקודות ההשקה.
(2)חשבו את השטח המוגבל על ידי גרף הפונקצייה f(x) ועל ידי שני המשיקים.
פתרון סעיף ד הדרך: הנקודה P אינה על הגרף, ולכן אי אפשר לגזור בה. הפתרון הרגיל הוא להפוך את הכיוון: מסמנים את נקודת ההשקה ב־(t , f(t)), כותבים את המשיק שם, ורק אז דורשים שיעבור דרך P. התנאי הזה הוא משוואה ב־t, ומספר פתרונותיה הוא מספר המשיקים. בסעיף (2) כדאי לנצל את הסימטרייה של הפרבולה ביחס לציר ה־y, ולחשב רק חצי מן השטח.
(1) f'(x) = 2x. נסמן את נקודת ההשקה ב־(t , t2 + 2); שיפוע המשיק שם הוא 2t, ולכן משוואת המשיק היא
y - (t2 + 2) = 2t(x - t)  ⇐⇒  y = 2t·x - t2 + 2.
המשיק עובר דרך P(0 , -2), ולכן -2 = -t2 + 2, כלומר t2 = 4 ומכאן t = 2 או t = -2.
המשיקים: y = 4x - 2, ונקודת ההשקה שלו (2 , 6); y = -4x - 2, ונקודת ההשקה שלו (-2 , 6).
(בדיקה: 4·2 - 2 = 6 = f(2) וגם f'(2) = 4, ובאותו אופן בצד השני.)
(2) בין x = -2 ל־x = 0 הגבול התחתון הוא המשיק השמאלי, ובין x = 0 ל־x = 2 הגבול התחתון הוא המשיק הימני; הגבול העליון בשני התחומים הוא הפרבולה. שתי הצורות סימטריות ביחס לציר ה־y, ולכן
S = 2·∫02 [(x2 + 2) - (4x - 2)] dx = 2·∫02 (x2 - 4x + 4) dx = 2·∫02 (x - 2)2 dx
= 2·[(x - 2)33]02 = 2·(0 - (-83)) = 163 ≈ 5.33.
(בדיקה עצמאית בדרך אחרת: המשולש שקודקודיו (-2 , 6) , (2 , 6) ו־P(0 , -2) בסיסו 4 וגובהו 8, ולכן שטחו 16. השטח שחושב הוא בדיוק שליש ממנו, 163, כפי שקורה תמיד בפרבולה ובשני משיקים מנקודה אחת.)

ה.מהו מספר האיברים הקטן ביותר בסדרה B שסכומם גדול מ־26.9?

בסרטוט שלפניכם מעגל שמרכזו O ורדיוסו r. מן הנקודה A יוצאות שתי קרניים, והמעגל משיק לשתיהן: לקרן האחת בנקודה B ולקרן האחרת בנקודה C.
ישר נוסף משיק למעגל בנקודה K, חותך את הקרן AB בנקודה M ואת הקרן AC בנקודה N (ראו סרטוט).
א.הוכיחו כי AB = AC, וכי הקטע AO חוצה את הזווית ∡BAC.
ב.הוכיחו כי היקף המשולש AMN שווה ל־2·AB.
נסמן: ∡BAC = 2α.
ג.הביעו באמצעות r ו־α את היקף המשולש AMN.
ד.נתון: r = 3, והיקף המשולש AMN הוא 63. מצאו את הערך של α.
ה.נתון בנוסף כי AM = AN. חשבו את שטח המשולש AMN ואת אורך הקטע AK.
פתרון הדרך: כל השאלה יושבת על משפט אחד - שני קטעי משיק למעגל מאותה נקודה שווים באורכם - אבל הוא מופעל שלוש פעמים, מן הנקודה A, מן הנקודה M ומן הנקודה N. התוצאה בסעיף ב מפתיעה: היקף המשולש AMN אינו תלוי כלל במקום שבו המשיק השלישי נוגע במעגל, ולכן אפשר לחשב אותו עוד לפני שיודעים איפה נמצאות M ו־N. סעיף ג מתרגם את ההיקף לשפה של r ו־α, סעיף ד מפעיל את אותו ביטוי בכיוון ההפוך, וסעיף ה מוסיף נתון סימטרייה שהופך את המשולש לשווה־צלעות.
א. AB ו־AC משיקים למעגל, ו־B ו־C הן נקודות ההשקה. הרדיוס אל נקודת ההשקה מאונך למשיק, ולכן ∡ABO = ∡ACO = 90°.
במשולשים ישרי־הזווית ABO ו־ACO: OB = OC = r (רדיוסים), ו־AO יתר משותף, ולכן המשולשים חופפים (יתר וניצב).
מן החפיפה: AB = AC וגם ∡BAO = ∡CAO, כלומר AO חוצה את הזווית ∡BAC. ∎
ב. הישר MN משיק למעגל בנקודה K. מן הנקודה M יוצאים שני משיקים למעגל, MB ו־MK, ולכן MK = MB; באותו אופן מן הנקודה N: NK = NC.
הנקודה K נמצאת בין M ל־N, ולכן MN = MK + KN, ומכאן:
היקף(AMN) = AM + MN + NA = AM + MK + KN + NA = (AM + MB) + (NC + NA) = AB + AC.
לפי סעיף א AB = AC, ולכן היקף(AMN) = 2·AB. ∎
(שימו לב: בשום מקום לא נעשה שימוש במיקומה של K, ולכן ההיקף זהה בעבור כל משיק שלישי.)
ג. לפי סעיף א, AO חוצה את ∡BAC = 2α, ולכן ∡BAO = α.
במשולש ישר־הזווית ABO (∡ABO = 90°) הניצב שמול הזווית α הוא OB = r, ולכן
tan α = rAB , כלומר AB = rtan α.
לפי סעיף ב: היקף(AMN) = 2·AB = 2rtan α.
ד. נציב r = 3 ונשווה להיקף הנתון:
6tan α = 63  ⇐⇒  tan α = 13  ⇐⇒  α = 30°.
(ואז ∡BAC = 60°, ובדיקה: AB = 3tan 30° = 33, ואכן 2·AB = 63.)
ה. נתון AM = AN, ולכן המשולש AMN שווה־שוקיים; זווית הראש שלו היא ∡MAN = ∡BAC = 60°, ולכן שתי זוויות הבסיס שוות ל־60° אף הן, והמשולש AMN הוא שווה־צלעות.
ההיקף הוא 63, ולכן אורך כל צלע הוא 633 = 23.
שטח(AMN) = 12·AM·AN·sin 60° = 12·(23)2·32 = 12·12·32 = 33 ≈ 5.20.
המשולש AMN שווה־צלעות, ולכן הסרטוט סימטרי ביחס לחוצה הזווית AO; מכאן ש־MN ⊥ AO, ונקודת ההשקה K היא אמצע MN ונמצאת על AO. לכן AK הוא הגובה לצלע MN במשולש שווה־צלעות שאורך צלעו 23:

פתרון הדרך: הפונקצייה היא הפרש בין שורש, שגדל לאט, ובין קו ישר, שגדל בקצב קבוע; לכן בהתחלה השורש מוביל והפונקצייה עולה, ובהמשך הישר גובר עליה והיא יורדת. זהו כל המבנה, ומכאן ברור מראש שיש בדיוק נקודת קיצון אחת והיא מקסימום. את הפרמטר לא מוצאים מנקודת הקיצון אלא משיפוע המשיק בנקודה קבועה, ולכן צריך תחילה נגזרת כללית. בסעיף ה מציבים ערך קבוע במקום f(x) ומתקבלת משוואה שהנעלם בה מופיע גם בתוך השורש וגם מחוצה לו; ההצבה t = x הופכת אותה למשוואה ריבועית רגילה. בסעיף ו אין לפתור אף משוואה: סופרים חיתוכים של הגרף עם ישרים אופקיים, ולכן מספיק לדעת את מהלך העלייה והירידה ואת הערכים בקצוות.
א. ביטוי השורש מחייב x ≥ 0, ולכן תחום ההגדרה הוא x ≥ 0.
חיתוך עם הצירים: ax - x = 0  ⇐⇒  x(a - x) = 0, ולכן x = 0 או x = a, כלומר x = 0 או x = a2.
הנקודות: (0 , 0) ו־(a2 , 0). (הנקודה (0 , 0) היא גם החיתוך עם ציר ה־y.)
ב. f'(x) = a2x - 1 , בעבור x > 0.
f'(x) = 0  ⇐⇒  2x = a  ⇐⇒  x = a2  ⇐⇒  x = a24.
f(a24) = a·a2 - a24 = a24.
סימני הנגזרת: כאשר 0 < x < a24 מתקיים 2x < a ולכן f' > 0 (עלייה); כאשר x > a24 מתקיים f' < 0 (ירידה).
לכן (a24 , a24) היא נקודת מקסימום.
ג. f'(1) = a2 - 1, ונתון כי שיפוע זה שווה ל־1:
a2 - 1 = 1  ⇐⇒  a = 4 (ואכן a > 0).
ד. בעבור a = 4: f(x) = 4x - x.
הגרף מתחיל בראשית הצירים (0 , 0) (שם המשיק אנכי), עולה עד נקודת המקסימום (4 , 4), יורד וחוצה את ציר ה־x בנקודה (16 , 0), וממשיך לרדת מתחת לציר. הגרף מוגדר רק מימין לציר ה־y (בתחום x ≥ 0).
ה. נדרוש f(x) = 3 , כלומר 4x - x = 3. נציב t = x , ואז x = t2 ומתקיים t ≥ 0:
4t - t2 = 3  ⇐⇒  t2 - 4t + 3 = 0  ⇐⇒  (t - 1)(t - 3) = 0 ,
ולכן t = 1 או t = 3 (שני הפתרונות אינם שליליים, ולכן שניהם מתאימים). מכאן x = t2 נותן x = 1 ו־x = 9.
שתי הנקודות הן (1 , 3) ו־(9 , 3).
שתי הנקודות נמצאות על הישר y = 3 , כלומר באותו גובה, ולכן אורך הקטע שביניהן הוא הפרש שיעורי ה־x:
9 - 1 = 8.
(בדיקה עצמאית: f(1) = 4·1 - 1 = 3 וכן f(9) = 4·3 - 9 = 3. שתי הנקודות אכן על הגרף, והן משני עברי נקודת המקסימום (4 , 4) שמצאנו בסעיף ב, כפי שהסקיצה שבסעיף ד מראה.)
ו. לפי סעיפים ב ו־ד: בתחום 0 ≤ x ≤ 4 הפונקצייה עולה מן הערך f(0) = 0 עד הערך f(4) = 4, ובתחום x ≥ 4 היא יורדת מן הערך 4 ושואפת ל־-∞. לכן:
k > 4: אין פתרון.
k = 4: פתרון יחיד, x = 4 (המקסימום).
0 ≤ k < 4: שני פתרונות, אחד בענף העולה ואחד בענף היורד (בעבור k = 0 אלה x = 0 ו־x = 16).
k < 0: בענף העולה כל הערכים הם בין 0 ל־4, ולכן יש פתרון יחיד, בענף היורד בלבד.
מסקנה: למשוואה f(x) = k יש פתרון יחיד כאשר k = 4 או k < 0.
7.
נתונה הפונקצייה f(x) = 12x2 + a.
a הוא פרמטר חיובי.
בסעיפים א-ג הביעו את תשובותיכם באמצעות a, אם יש צורך.
א.מצאו את תחום ההגדרה של הפונקצייה f(x) ואת שיעורי נקודת החיתוך של הגרף שלה עם ציר ה־y, הוכיחו כי הגרף אינו חותך את ציר ה־x, ורשמו את משוואת האסימפטוטה שלה המקבילה לציר ה־x.
ב.מצאו את שיעורי נקודת הקיצון של הפונקצייה f(x), קבעו את סוגה, ורשמו את תחומי העלייה והירידה של הפונקצייה.
ג.מצאו את שיעורי ה־x של נקודות הפיתול של גרף הפונקצייה f(x).
ד.נתון כי נקודות הפיתול של הגרף הן הנקודות שבהן x = 2 ו־x = -2. מצאו את הערך של a.
בעבור הערך של a שמצאתם בסעיף ד, ענו על הסעיפים ה-ו.
ה.סרטטו סקיצה של גרף הפונקצייה f(x).
ו.מצאו את משוואת המשיק לגרף הפונקצייה f(x) בנקודת הפיתול שבה x = 2, וחשבו את שטח המשולש שהמשיק הזה יוצר עם הצירים.
פתרון הדרך: הנתון a > 0 הוא לב השאלה, ולא הערה טכנית: הוא מבטיח שהמכנה x2 + a חיובי תמיד, ולכן אין כאן אסימפטוטה מאונכת, אין נקודות חיתוך עם ציר ה־x, והפונקצייה כולה חיובית. מה שנשאר לחקור הוא הצורה: פסגה אחת בלבד באמצע, שתי "כתפיים" שבהן הקעירות מתהפכת, וירידה אל האסימפטוטה y = 0 משני הצדדים. שימו לב שהפרמטר נקבע כאן לא מערך של הפונקצייה אלא ממקום של נקודות הפיתול, ולכן צריך את הנגזרת השנייה עוד לפני שיודעים מהו a.
א. נתון a > 0, ולכן x2 + a ≥ a > 0 לכל x: המכנה אינו מתאפס אף פעם, ותחום ההגדרה הוא כל x (ואין לגרף אסימפטוטה מאונכת לציר ה־x).
חיתוך עם ציר ה־y: f(0) = 12a, כלומר הנקודה (0 , 12a).
חיתוך עם ציר ה־x: שבר מתאפס רק כאשר המונה מתאפס, והמונה כאן הוא המספר הקבוע 12 ≠ 0, ולכן f(x) ≠ 0 לכל x והגרף אינו חותך את ציר ה־x. ∎
כאשר |x| גדל, המכנה גדל ללא גבול בעוד המונה קבוע, ולכן f(x) שואף לאפס: האסימפטוטה המקבילה לציר ה־x היא y = 0.
ב. נגזור לפי כלל המנה (או ככפל בחזקה שלילית):
f'(x) = 0·(x2 + a) - 12·2x(x2 + a)2 = -24x(x2 + a)2.
המכנה חיובי תמיד, ולכן סימן הנגזרת הוא סימן -24x: בעבור x < 0 מתקיים f' > 0 (עלייה), ובעבור x > 0 מתקיים f' < 0 (ירידה).
f'(x) = 0 רק ב־x = 0, והנגזרת מחליפה שם סימן מחיובי לשלילי, ולכן זו נקודת מקסימום: (0 , 12a).
עלייה: x < 0. ירידה: x > 0.
ג. נגזור שוב, ונוציא במונה גורם משותף (x2 + a):
f''(x) = -24(x2 + a)2 + 24x·2(x2 + a)·2x(x2 + a)4 = -24(x2 + a) + 96x2(x2 + a)3 = 24(3x2 - a)(x2 + a)3.
המכנה חיובי תמיד, ולכן סימן הנגזרת השנייה הוא סימן 3x2 - a, והיא מתאפסת כאשר
x2 = a3  ⇐⇒  x = ±a3.
בכל אחת משתי הנקודות האלה הביטוי 3x2 - a מחליף סימן (הוא פרבולה שקודקודה מתחת לציר), ולכן שתיהן נקודות פיתול.
ד. נתון כי הפיתול מתקבל ב־x = ±2, ולכן
a3 = 4  ⇐⇒  a = 12.
(בדיקה: בעבור a = 12 מתקבל f''(x) = 24(3x2 - 12)(x2 + 12)3 = 72(x2 - 4)(x2 + 12)3, ואכן מתאפס ב־x = ±2 בלבד.)
ה. בעבור a = 12: f(x) = 12x2 + 12.
f(0) = 1 - מקסימום ב־(0 , 1); f(±2) = 1216 = 0.75 - נקודות פיתול (2 , 0.75) ו־(-2 , 0.75).
סקיצה: הגרף כולו מעל ציר ה־x וסימטרי ביחס לציר ה־y (מתקיים f(-x) = f(x)): הוא עולה משמאל, מגיע לפסגה (0 , 1), יורד מימין, עובר בנקודות הפיתול (±2 , 0.75) שבהן הקעירות מתהפכת מכלפי מטה לכלפי מעלה, ומתקרב אל האסימפטוטה y = 0 מלמעלה בשני הכיוונים.
ו. f(2) = 0.75 , f'(2) = -24·2(4 + 12)2 = -48256 = -316 = -0.1875.
משוואת המשיק: y - 0.75 = -0.1875(x - 2), כלומר
y = -316x + 98  (y = -0.1875x + 1.125).
חיתוך עם ציר ה־y: (0 , 1.125). חיתוך עם ציר ה־x: 0.1875x = 1.125, כלומר x = 6, ומכאן הנקודה (6 , 0).
המשולש שנוצר הוא ישר־זווית, וניצביו מונחים על הצירים:
S = 12·6·1.125 = 3.375 = 278.
(בדיקה שהמשיק אכן עובר בנקודת הפיתול: -0.1875·2 + 1.125 = -0.375 + 1.125 = 0.75 = f(2).)
8.
נתונות שתי הפונקציות f(x) = sin x ו־g(x) = cos 2x בתחום 0 ≤ x ≤ 2π.
א.מצאו את שיעורי כל הנקודות המשותפות לשני הגרפים בתחום הנתון.
ב.הוכיחו כי בנקודה המשותפת שבה x = 3π2 יש לשני הגרפים משיק משותף, ורשמו את משוואתו.
ג.סרטטו סקיצה של שני הגרפים באותה מערכת צירים, בתחום הנתון.
ד.מצאו את הערך הגדול ביותר של ההפרש f(x) - g(x) בתחום π6 ≤ x ≤ 5π6, ואת הערך של x שבעבורו הוא מתקבל.
ה.חשבו את השטח הכלוא בין שני הגרפים בתחום π6 ≤ x ≤ 5π6.
ו.חשבו את השטח הכלוא בין שני הגרפים בתחום 5π6 ≤ x ≤ 3π2.
פתרון הדרך: שני הגרפים כתובים בשתי "שפות" שונות, אחד ב־x ואחד ב־2x, ולכן הצעד הראשון בכל סעיף הוא זהות הזווית הכפולה cos 2x = 1 - 2sin2x: היא מתרגמת את הכול ל־sin x ומשאירה משוואה ריבועית פשוטה. שימו לב להבדל בין הנקודות המשותפות: בשתיים מהן הגרפים נחתכים ועוברים זה דרך זה, ובשלישית הם רק נוגעים - שם שתי הפונקציות מקבלות את הערך הקטן ביותר האפשרי שלהן, -1, ולכן אף אחת מהן אינה יכולה לרדת מתחת לשנייה. סעיפים ה ו־ו הם אותו אינטגרל בדיוק, אבל עם היפוך התפקידים בין הפונקציות, כי בכל תחום גרף אחר נמצא למעלה.
א. נקודה משותפת מקיימת sin x = cos 2x. לפי זהות הזווית הכפולה:
sin x = 1 - 2sin2x  ⇐⇒  2sin2x + sin x - 1 = 0  ⇐⇒  (2sin x - 1)(sin x + 1) = 0.
sin x = 12  →  x = π6 או x = 5π6 ; sin x = -1  →  x = 3π2.
הנקודות המשותפות: (π6 , 0.5) , (5π6 , 0.5) , (3π2 , -1).
(בדיקה בנקודה השנייה: sin 5π6 = 0.5 וגם cos 5π3 = 0.5.)
ב. f'(x) = cos x , g'(x) = -2·sin 2x. נציב x = 3π2:
f'(3π2) = cos 3π2 = 0 , g'(3π2) = -2·sin 3π = 0.
לשני הגרפים יש אפוא נקודה משותפת אחת ובה גם שיפוע זהה, ולכן יש להם באותה נקודה משיק משותף. ∎
המשיק עובר בנקודה (3π2 , -1) ושיפועו 0, ולכן משוואתו היא y = -1.
(זה גם ההסבר הגאומטרי: -1 הוא הערך הקטן ביותר של sin x וגם של cos 2x, ולכן שני הגרפים נוגעים שם בישר y = -1 מלמעלה ואינם חוצים אותו.)
ג. סקיצה: f(x) = sin x יוצא מן הראשית, מגיע למקסימום (π2 , 1), חוצה את הציר ב־x = π ומגיע למינימום (3π2 , -1), וחוזר אל (2π , 0).
g(x) = cos 2x הוא גל בעל מחזור π: הוא יוצא מן הנקודה (0 , 1), יורד למינימום (π2 , -1), עולה למקסימום (π , 1), יורד שוב למינימום (3π2 , -1) ועולה אל (2π , 1). הוא חוצה את ציר ה־x ב־π4 , 3π4 , 5π4 , 7π4.
שני הגרפים נפגשים בשלוש הנקודות שנמצאו בסעיף א, וב־x = 3π2 הם נוגעים זה בזה בלי לחצות.
ד. נסמן d(x) = f(x) - g(x) = sin x - cos 2x. נגזור:
d'(x) = cos x + 2·sin 2x = cos x + 4·sin x·cos x = cos x·(1 + 4·sin x).
בתחום π6 ≤ x ≤ 5π6 מתקיים sin x ≥ 0.5, ולכן 1 + 4·sin x ≥ 3 > 0 ואפשר להתעלם מן הגורם הזה: סימן הנגזרת הוא סימן cos x.
d'(x) = 0  ⇐⇒  cos x = 0  ⇐⇒  x = π2 ; לפניה cos x > 0 (עלייה) ואחריה cos x < 0 (ירידה), ולכן זו נקודת מקסימום.
d(π2) = sin π2 - cos π = 1 - (-1) = 2.
ההפרש הגדול ביותר הוא 2, והוא מתקבל ב־x = π2. (בקצות התחום ההפרש הוא 0, כי שם הגרפים נפגשים.)
(בדיקה בלי גזירה: d(x) = sin x - (1 - 2sin2x) = 2sin2x + sin x - 1. זהו ביטוי ריבועי ב־sin x שמקדמו חיובי, ולכן בתחום 0.5 ≤ sin x ≤ 1 הוא גדל עם sin x ומקבל את ערכו הגדול ביותר כאשר sin x = 1: 2 + 1 - 1 = 2.)
ה. בתחום π6 ≤ x ≤ 5π6 מתקיים d(x) ≥ 0 (לפי סעיף ד), כלומר גרף f נמצא מעל גרף g, ולכן
S = ∫ (sin x - cos 2x) dx בין הגבולות, והקדומה היא F(x) = -cos x - 12·sin 2x.
F(5π6) = -cos 5π6 - 12·sin 5π3 = 32 + 34 = 334
F(π6) = -cos π6 - 12·sin π3 = -32 - 34 = -334
S = 334 - (-334) = 332 ≈ 2.60.
(בדיקת סבירות: רוחב התחום הוא 2π3 ≈ 2.09 וגובה הגוש המרבי הוא 2, ולכן שטח של כ־2.6 הוא בדיוק בסדר הגודל הצפוי מגוש בעל קצוות מחודדים.)
ו. בתחום 5π6 ≤ x ≤ 3π2 התהפכו התפקידים: למשל ב־x = π מתקיים g(π) = cos 2π = 1 ואילו f(π) = 0, ולכן גרף g נמצא למעלה. הקדומה של cos 2x - sin x היא G(x) = 12·sin 2x + cos x.
G(3π2) = 12·sin 3π + cos 3π2 = 0 + 0 = 0
G(5π6) = 12·sin 5π3 + cos 5π6 = -34 - 32 = -334
S = 0 - (-334) = 334 ≈ 1.30.
(שימו לב שהשטח הזה הוא בדיוק מחצית מן השטח שבסעיף ה, אף על פי ששני התחומים שווים באורכם: הגוש השני נמוך יותר וגם נסגר בנגיעה ולא בחיתוך.)
