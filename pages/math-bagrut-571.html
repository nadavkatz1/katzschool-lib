פרק ראשון - שאלות קצרות
1.
ענו על שניים מארבעת הסעיפים א-ד שלפניכם. אם תענו על יותר משני סעיפים, ייבדקו רק שתי התשובות הראשונות שבמחברתכם.
א.
(1)הוכיחו באינדוקצייה מתמטית, או בכל דרך אחרת, כי לכל n טבעי מתקיים:
11·3 + 13·5 + 15·7 + ... + 1(2n - 1)(2n + 1) = n2n + 1
(2)מצאו את המספר הטבעי n שבעבורו הסכום שבאגף שמאל של השוויון שווה ל־0.48.
פתרון סעיף א הדרך: השוויון מנוסח לכל n טבעי, ואי אפשר לבדוק אין־סוף מקרים אחד־אחד - זה בדיוק המצב שבו האינדוקצייה היא הכלי. בודקים את n = 1, מניחים שהשוויון נכון בעבור n ומוסיפים לשני האגפים את האיבר הבא, 1(2n + 1)(2n + 3). כל העבודה בצעד היא איחוד שני שברים למכנה משותף, ואז המונה שמתקבל מתפרק לגורמים ומצטמצם עם המכנה. בסעיף (2) הסכום כבר ידוע כפונקצייה של n, ולכן משווים את הביטוי הזה למספר הנתון ופותרים משוואה אחת בנעלם אחד.
(1) בסיס האינדוקצייה (n = 1): אגף שמאל 11·3 = 13; אגף ימין 12·1 + 1 = 13. השוויון מתקיים.
צעד האינדוקצייה: נניח כי בעבור n מסוים מתקיים 11·3 + ... + 1(2n - 1)(2n + 1) = n2n + 1, ונוכיח בעבור n + 1. האיבר ה־(n + 1) בסכום הוא 1(2n + 1)(2n + 3), ולכן:
n2n + 1 + 1(2n + 1)(2n + 3) = n(2n + 3) + 1(2n + 1)(2n + 3) = 2n² + 3n + 1(2n + 1)(2n + 3).
המונה מתפרק: 2n² + 3n + 1 = (2n + 1)(n + 1), ולכן
(2n + 1)(n + 1)(2n + 1)(2n + 3) = n + 12n + 3 = n + 12(n + 1) + 1,
וזהו בדיוק אגף ימין של השוויון בעבור n + 1. מן הבסיס והצעד, לפי עקרון האינדוקצייה, השוויון מתקיים לכל n טבעי.
(2) לפי השוויון שהוכחנו, הסכום שווה ל־n2n + 1, ולכן נפתור:
n2n + 1 = 0.48  ⇐⇒  n = 0.48(2n + 1) = 0.96n + 0.48  ⇐⇒  0.04n = 0.48  ⇐⇒  n = 12.
(בדיקה: 122·12 + 1 = 1225 = 0.48.)
ב. בקופסה 12 כרטיסים: k מהם אדומים, ושאר הכרטיסים כחולים (0 < k < 12).
מוציאים מן הקופסה באקראי שני כרטיסים בזה־אחר־זה, ללא החזרה.
(1)הביעו באמצעות k את ההסתברות שהכרטיס השני שהוצא הוא אדום.
(2)ידוע כי הכרטיס השני שהוצא הוא אדום. נתון כי ההסתברות שגם הכרטיס הראשון היה אדום היא 211. מצאו את הערך של k.
(3)בעבור הערך של k שמצאתם, מוציאים מן הקופסה באקראי ארבעה כרטיסים בזה־אחר־זה, ללא החזרה. מהי ההסתברות שכל הכרטיסים האדומים שהיו בקופסה נמצאים בין ארבעת הכרטיסים שהוצאו?
פתרון סעיף ב הדרך: ההסתברות של הכרטיס השני אינה ידועה מראש, כי היא תלויה במה שיצא ראשון - ולכן מפצלים לשני מסלולים זרים לפי צבע הכרטיס הראשון ומחברים. הביטוי שמתקבל מצטמצם לביטוי פשוט להפתיע, וזה אינו צירוף מקרים: לכרטיסים אין "זיכרון" של סדר ההוצאה, ולכן ההסתברות שהשני אדום שווה להסתברות שהראשון אדום. בסעיף (2) הנתון הוא הסתברות מותנית שכיוונה הפוך לכיוון הטבעי - מן הכרטיס השני אל הראשון - ולכן מפעילים את הגדרת ההסתברות המותנית ומציבים במכנה בדיוק את הביטוי מסעיף (1); המכנה מצטמצם, והמשוואה שנשארת היא לינארית. בסעיף (3) אין כאן התניה כלל אלא ספירה: כמה מן הרביעיות האפשריות מכילות את כל הכרטיסים האדומים.
(1) מספר הכרטיסים הכחולים הוא 12 - k. נפצל לפי צבע הכרטיס הראשון:
P(ראשון אדום ו־שני אדום) = k12 · k - 111 , P(ראשון כחול ו־שני אדום) = 12 - k12 · k11.
שני המסלולים זרים, ולכן
P(שני אדום) = k(k - 1) + k(12 - k)12·11 = k² - k + 12k - k²132 = 11k132 = k12.
זו בדיוק ההסתברות שהכרטיס הראשון אדום - סדר ההוצאה אינו משנה.
(2) לפי הגדרת ההסתברות המותנית, ובעזרת שני הביטויים שכבר חישבנו:
P(ראשון אדום | שני אדום) = P(שניהם אדומים)P(שני אדום) = k(k - 1)132k12 = k - 111.
נתון כי הביטוי הזה שווה ל־211, ולכן k - 1 = 2, כלומר k = 3 (ואכן 0 < 3 < 12).
(3) בקופסה 3 כרטיסים אדומים ו־9 כחולים. מוציאים ארבעה כרטיסים; מספר הרביעיות האפשריות הוא C(12,4) = 12·11·10·94·3·2·1 = 495.
רביעייה מתאימה חייבת להכיל את שלושת האדומים ועוד כרטיס כחול אחד, ולכן מספר הרביעיות המתאימות הוא C(3,3)·C(9,1) = 9.
P = 9495 = 155 ≈ 0.018.
(בדיקה בדרך ההוצאה בזה־אחר־זה: הכרטיס הכחול היחיד יכול לצאת באחד מ־4 המקומות, ובעבור מקום קבוע ההסתברות היא 3·2·1·912·11·10·9, ולכן P = 4·5411880 = 21611880 = 155.)
ג. בסרטוט שלפניכם מעגל שמרכזו O. הקטע AB הוא קוטר במעגל, והנקודה C נמצאת על המעגל. המשיק למעגל בנקודה B חותך את המשך הקטע AC בנקודה D (ראו סרטוט).
נסמן: ∡BAC = α (0° < α < 90°).
(1)הביעו באמצעות α את היחס בין שטח המשולש ABC ובין שטח המשולש ABD.
(2)נתון כי שטח המשולש ABD גדול פי 4 משטח המשולש ABC. מצאו את הערך של α.
פתרון סעיף ג הדרך: בסרטוט הזה יש שתי זוויות ישרות שמגיעות משני משפטים שונים לגמרי: הזווית ההיקפית הנשענת על קוטר היא ישרה, והמשיק מאונך לרדיוס בנקודת ההשקה. כל אחת מהן יושבת במשולש אחר, ולשני המשולשים משותפת הזווית α שבקדקוד A ומשותף היתר-או-הניצב AB. לכן אפשר לבטא את כל האורכים הדרושים באמצעות AB ו־α בלבד, ובחישוב היחס האורך המשותף מצטמצם ונשאר ביטוי בזווית בלבד - זו הסיבה שאין צורך באף נתון מספרי.
(1) נסמן AB = d.
∡ACB = 90° - זווית היקפית הנשענת על הקוטר AB. במשולש ישר־הזווית ACB:
AC = d·cos α , BC = d·sin α, ולכן S(ABC) = 12·AC·BC = 12d²·sin α·cos α.
∡ABD = 90° - המשיק בנקודה B מאונך לרדיוס OB, והרדיוס OB נמצא על הקוטר AB. הזווית ∡BAD היא אותה זווית α, שכן D נמצאת על המשך AC. במשולש ישר־הזווית ABD:
BD = d·tan α, ולכן S(ABD) = 12·AB·BD = 12d²·tan α.
S(ABC)S(ABD) = sin α·cos αtan α = sin α·cos α·cos αsin α = cos²α.
(בדיקה: בעבור α = 45° מתקבל יחס 0.5; ואכן אז AC = BC = d2 ו־BD = d, כלומר S(ABC) = d²4 ו־S(ABD) = d²2.)
(2) הנתון אומר S(ABC)S(ABD) = 14, ולכן cos²α = 14.
בתחום 0° < α < 90° מתקיים cos α > 0, ולכן cos α = 12, כלומר α = 60°.
ד. הפונקצייה f(x) ופונקציית הנגזרת שלה f'(x) מוגדרות לכל x. בסרטוט שלפניכם גרף פונקציית הנגזרת f'(x).
(1)מצאו את שיעורי ה־x של נקודות הקיצון של הפונקצייה f(x), וקבעו את סוגן. נמקו את תשובתכם.
(2)לפניכם ארבעה גרפים I-IV. בכל אחד מהם מסומנים שיעורי ה־x של כל נקודות הקיצון שלו. קבעו איזה מן הגרפים יכול לתאר את גרף הפונקצייה f(x). נמקו את קביעתכם.
פתרון סעיף ד הדרך: גרף הנגזרת אינו מראה את ערכי הפונקצייה, אבל הוא מראה בדיוק דבר אחד שמספיק כאן: את הסימן של f'(x). במקום שבו גרף הנגזרת נמצא מעל ציר ה־x הפונקצייה עולה, ובמקום שבו הוא מתחתיו היא יורדת. נקודת קיצון נוצרת רק היכן שהסימן מתחלף, וכיוון ההתחלפות הוא שקובע אם זה מקסימום או מינימום. בסעיף (2) אין צורך לחשב דבר: בודקים כל גרף מועמד לפי שני קריטריונים בלבד - כמה נקודות קיצון יש לו, ובאילו שיעורי x הן יושבות ומאיזה סוג.
(1) מן הסרטוט, גרף הנגזרת חותך את ציר ה־x בנקודות x = -1 ו־x = 3 בלבד, ולכן:
בעבור x < -1: f'(x) > 0 (הגרף מעל הציר) - הפונקצייה עולה;
בעבור -1 < x < 3: f'(x) < 0 - הפונקצייה יורדת;
בעבור x > 3: f'(x) > 0 - הפונקצייה עולה.
ב־x = -1 הנגזרת מתחלפת מחיובית לשלילית, ולכן זו נקודת מקסימום; ב־x = 3 הנגזרת מתחלפת משלילית לחיובית, ולכן זו נקודת מינימום.
(2) הגרף המתאים הוא III: רק בו יש מקסימום ב־x = -1 ומינימום ב־x = 3, בדיוק כפי שקבענו בסעיף (1).
מדוע לא האחרים: בגרף I נקודות הקיצון נמצאות בשיעורי ה־x הנכונים אבל סוגן הפוך (מינימום ב־x = -1 ומקסימום ב־x = 3); לגרף II יש נקודת קיצון אחת בלבד, ואילו לנגזרת שלנו שתי נקודות התאפסות עם החלפת סימן; בגרף IV נקודות הקיצון נמצאות ב־x = 1 וב־x = 4, ואילו הנגזרת הנתונה מתאפסת ב־x = -1 וב־x = 3.
פרק שני - אינדוקצייה, סדרות והסתברות
2.
נתונה סדרה הנדסית אין־סופית A שאיבריה a₁, a₂, a₃, ... ומנתה q, ונתון |q| < 1.
נתון כי סכום כל איברי הסדרה A הוא 27, וכי סכום האיברים שבמקומות האי־זוגיים, a₁ + a₃ + a₅ + ..., הוא 18.
א.
(1)הוכיחו כי הסדרה שאיבריה a₁, a₃, a₅, ... היא סדרה הנדסית שמנתה q².
(2)מצאו את הערך של q.
ב.מצאו את הערך של a₁.
ג. מצאו את סכום הסדרה האין־סופית שאיבריה a₂, a₄, a₆, ...
ד. מצאו את סכום הסדרה האין־סופית שאיבריה a₁², a₂², a₃², ...
פתרון הדרך: שני הנתונים כאן הם שני סכומים אין־סופיים של אותה סדרה, ולכן אין טעם לחפש תחילה את a₁. תת־הסדרה של המקומות האי־זוגיים היא בעצמה הנדסית, ומנתה q² - כי בין שני איברים שכנים בתוכה יש שני צעדים בסדרה המקורית. ברגע שכותבים את שני הסכומים זה מול זה, a₁ מצטמצם בחלוקה ונשארת משוואה אחת ב־q בלבד, ואפילו לינארית. סעיף ג אינו דורש חישוב חדש כלל: המקומות הזוגיים הם כל מה שנשאר מן הסכום הכולל אחרי שמורידים ממנו את המקומות האי־זוגיים. בסעיף ד חוזר אותו רעיון של סעיף א(1) בגרסה אחרת - כשמעלים את כל האיברים בריבוע, המנה עולה בריבוע גם היא, ולכן |q²| < 1 וגם הסדרה הזאת מתכנסת.
א(1) הוכחה: נסמן ב־cₖ את האיבר ה־k בסדרה החדשה, כלומר cₖ = a₂ₖ₋₁. בסדרה הנדסית aₘ₊₁ = aₘ·q לכל m, ולכן שני צעדים קדימה הם כפל ב־q²:
cₖ₊₁cₖ = a₂ₖ₊₁a₂ₖ₋₁ = q²

ד.נסמן ב־S את שטח המשולש APB. הביעו באמצעות S את שטח המשולש ABC.
פתרון הדרך: אין בשאלה הזאת אף נתון מספרי, ולכן כל התשובות חייבות לצאת מיחסים בלבד. שני משיקים היוצאים מאותה נקודה שווים באורכם, והרדיוסים אל נקודות ההשקה שווים גם הם - שתי העובדות האלה יחד מציבות את P ואת O על האנך האמצעי של AB, ולכן M היא אמצע AB. זו הנקודה שממנה נפתח הכול: O היא אמצע הקוטר AC, ולכן MO הוא קטע אמצעים במשולש ABC - וזה כל סעיף ב. בסעיף ג מתרגמים את השאלה על שני המיתרים לשאלה על שני הניצבים OM ו־AM באותו משולש ישר־זווית, ושם ההשוואה ביניהם היא פשוט השוואה בין הקוסינוס לסינוס של אותה זווית, כלומר תנאי על גודלה. בסעיף ד שני המשולשים נשענים על אותו הבסיס AB, ולכן יחס השטחים הוא יחס הגבהים בלבד - ואת שני הגבהים אפשר לבטא באמצעות הרדיוס לאחר שהיחס PA : R נקבע.
א. הוכחה:
(1) PA = PB - שני משיקים היוצאים מנקודה אחת אל מעגל שווים זה לזה.
(2) OA = OB - רדיוסים באותו מעגל.
(3) מ־(1) ו־(2): הנקודות P ו־O שתיהן שוות־מרחק מ־A ומ־B, ולכן הישר PO הוא האנך האמצעי של המיתר AB; בפרט PO ⊥ AB.
(4) הזווית ∠ABC = 90° - זווית היקפית הנשענת על הקוטר AC; מכאן BC ⊥ AB.
(5) מ־(3) ו־(4): BC ו־PO שניהם מאונכים לישר AB, ושני ישרים המאונכים לאותו ישר מקבילים זה לזה. לכן BC ∥ PO. מ.ש.ל.
ב. הוכחה:

המשיק מאונך לרדיוס, ולכן במשולש ישר־הזווית OAP מתקיים tan θ = PAR, ולכן θ < 45° אם ורק אם PA < R.

ה.סרטטו סקיצה של גרף הפונקצייה f(x).
ו.מצאו בעבור אילו ערכים של k אין למשוואה f(x) = k אף פתרון.
פתרון הדרך: הפונקצייה היא מנה, ולכן הצעד הראשון הוא לשאול מתי המכנה מתאפס: שם נשבר התחום ושם יושבת האסימפטוטה האנכית. המונה הוא ריבוע של גורם לינארי, ולכן הוא מתאפס בנקודה אחת בלבד ואינו יורד מתחת לאפס - וזו הסיבה שנקודת החיתוך עם ציר ה־x היא גם נקודת השקה. את הגזירה נוח לבצע אחרי חלוקה איבר־איבר, כי אז הפונקצייה נכתבת כסכום של שלושה איברים פשוטים והנגזרת יוצאת הפרש של שניים בלבד. בסעיף ד שיפוע המשיק בנקודה הוא ערך הנגזרת בה, ולכן הנתון הופך למשוואה ב־a. בסעיף ו אין צורך לספור חיתוכים על הסקיצה: מספיק לקרוא ממנה את טווח הערכים של כל ענף, ולראות איזה פער ערכים אינו מתקבל כלל - ואפשר גם לאמת זאת בדיסקרימיננטה של משוואה ריבועית.
א. המכנה מתאפס כאשר x = 0, ולכן תחום ההגדרה הוא x ≠ 0.
כאשר x → 0 המונה שואף ל־a² שהוא חיובי (a > 0), והמכנה שואף לאפס, ולכן f(x) → +∞ כאשר x → 0⁺ ו־f(x) → -∞ כאשר x → 0⁻. לכן x = 0 היא אסימפטוטה אנכית, כלומר האסימפטוטה המאונכת לציר ה־x.
ב. נחלק איבר־איבר: f(x) = x² - 2ax + a²x = x - 2a + a²x, ולכן
f'(x) = 1 - a²x² = x² - a²x².
f(x) = 0 רק כאשר (x - a)² = 0, כלומר x = a (והוא בתחום, שכן a > 0). בנקודה זו f'(a) = a² - a²a² = 0, ולכן שיפוע המשיק בה הוא 0 והמשיק הוא הישר y = 0 - כלומר ציר ה־x עצמו. לכן הגרף משיק לציר ה־x, ונקודת ההשקה היא (a , 0). מ.ש.ל.
(אין לגרף נקודת חיתוך עם ציר ה־y, שכן x = 0 אינו בתחום ההגדרה.)
ג. f'(x) = x² - a²x². המכנה חיובי לכל x ≠ 0, ולכן סימן הנגזרת הוא סימן המונה x² - a²:
בעבור |x| > a: f'(x) > 0 - עלייה; בעבור 0 < |x| < a: f'(x) < 0 - ירידה.
f'(x) = 0 כאשר x = a או x = -a.
ב־x = a הנגזרת מתחלפת משלילית לחיובית, ולכן (a , 0) נקודת מינימום (f(a) = (a - a)²a = 0);
ב־x = -a הנגזרת מתחלפת מחיובית לשלילית, ולכן (-a , -4a) נקודת מקסימום (f(-a) = (-a - a)²-a = 4a²-a = -4a).
תחומי עלייה: x < -a או x > a; תחומי ירידה: -a < x < 0 וכן 0 < x < a.
ד. f'(1) = 1² - a²1² = 1 - a²1 = 1 - a². מן הנתון 1 - a² = -8, ולכן a² = 9, ומכיוון ש־a חיובי: a = 3.
ה. בעבור a = 3: f(x) = (x - 3)²x, אסימפטוטה אנכית x = 0, מינימום (3 , 0) ומקסימום (-3 , -12).
הסקיצה: הענף הימני (x > 0) יורד מ־+∞ בסמוך לאסימפטוטה עד לנקודה (3 , 0), שבה הוא נוגע בציר ה־x בלי לחצות אותו, ומשם עולה ללא גבול; הענף השמאלי (x < 0) עולה מ־-∞ עד למקסימום (-3 , -12) ומשם יורד ל־-∞ בסמוך לאסימפטוטה. כל הענף השמאלי נמצא מתחת לציר ה־x.
ו. מסעיף ג ומן הסקיצה: על הענף הימני הפונקצייה יורדת מ־+∞ עד 0 ואז עולה חזרה ל־+∞, ולכן היא מקבלת שם בדיוק את הערכים k ≥ 0; על הענף השמאלי היא עולה מ־-∞ עד -12 ואז יורדת חזרה ל־-∞, ולכן היא מקבלת שם בדיוק את הערכים k ≤ -12.
